## What's new (23 October 2026)

This is the first release of the fork's current `stable` branch. It combines newer upstream code with today's calendar sync improvements.

### Safer, more reliable sync

- Protect existing target events when a source fetch fails, a source is unexpectedly empty, or a target event page cannot be read completely. `skipIfEmptyFeed` is enabled by default and can be overridden per source.
- Prevent overlapping sync runs with a script lock. Isolate event write failures, handle already-deleted events, and report failed removals accurately.
- Bound cleanup with `maxCleanupDeletesPerRun` (default 100), resume across runs, and optionally skip old completed events with `pastEventWindowDays`.
- Require an exact, writable target calendar. Use `targetId` to disambiguate names; creation of a missing target now requires `createTargetCalendarIfMissing: true`. Target lists are paginated, and progress logs help locate long-running failures.

### More source and event options

- Configure per-source overrides for sync behavior, colours, reminders, title prefixes, filtering, and cleanup. Legacy array mappings remain supported.
- Sync Google Calendar sources as well as ICS feeds, including recurring events and exceptions. Source-specific event identity prevents two feeds with the same UID from overwriting one another.
- Decode ICS as UTF-8, validate HTTPS certificates, and support VFREEBUSY-only feeds.
- Improve recurring-event handling for moved Outlook occurrences and cancelled instances. Preserve named timezones and add Webex timezone aliases.
- Preserve valid HTML descriptions, map Microsoft tentative events to free when enabled, decode Outlook Safe Links when enabled, and improve reminder precedence and email summaries.

### Updates, documentation, and checks

- Add a release-aware auto-updater with pinned downloads, preview mode, optional email notices, and optional GitHub token support. Private `Config.gs` and `Filters.gs` are retained during automatic updates.
- Document installation, configuration, recovery, and diagnostics. Add GitHub Actions checks and regression coverage; all 76 local tests pass.

### Before updating

- If your setup relied on automatic creation of a missing target calendar, set `createTargetCalendarIfMissing: true` for that mapping, then record its `targetId` after creation.
- Review the new `skipIfEmptyFeed` and `maxCleanupDeletesPerRun` defaults. An intentionally empty source needs `skipIfEmptyFeed: false` to allow cleanup.
- Back up private `Config.gs` and `Filters.gs`, review Apps Script manifest scopes, and reauthorize from the editor if prompted.

Live Google Calendar behavior has not been verified by the local test suite. See `README.md` and `IMPROVEMENTS.md` for configuration details and remaining work.
